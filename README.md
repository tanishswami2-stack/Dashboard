
# Starbucks Sales and Profit Analysis Dashboard

## Project Overview
This project focuses on analysing Starbucks sales and estimated profit performance using an interactive Power BI dashboard. It helps understand business performance through key metrics and visualisations.

## Project Objectives
- Analyse total sales and estimated profit.
- Monitor monthly revenue and profit trends.
- Compare sales performance across different cities.
- Analyse product category performance.
- Present business insights through interactive visualisations.

## Tools and Technologies
- Microsoft Excel – Data cleaning and preparation
- Power BI – Dashboard development and visualisation
- DAX – Calculated measures and KPIs

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Estimated Profit
- Estimated Profit Margin
- Total Stores

## Dashboard Features
- Monthly Revenue and Profit Analysis
- City-wise Performance Analysis
- Category-wise Sales Analysis
- Interactive Filters and Slicers
- KPI Cards and Charts

## Dataset
The project uses a Starbucks India sales dataset containing store, city, category, and monthly sales information.

## Project Structure
- Dataset – Excel dataset used for analysis
- Screenshots – Dashboard visual previews
- Documentation – Project report
- System_Design – Waterfall model diagram

## Expected Outcome
An interactive dashboard that presents Starbucks sales and estimated profit insights in a clear and understandable format.
